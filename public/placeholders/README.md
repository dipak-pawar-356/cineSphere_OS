# CineSphere OS - Static Placeholder Assets Directory

This directory provides standardized placeholder assets (SVG and raster) for offline development, local mocking, fallback imagery, and testing before production CDN assets are provisioned.

## Directory Structure

```
public/placeholders/
├── movies/
│   ├── posters/          # Aspect ratio 2:3 vertical posters (e.g. 500x750)
│   └── banners/          # Aspect ratio 16:9 / 21:9 backdrop banners (e.g. 1920x1080)
├── theatres/
│   ├── logos/            # 1:1 square chain & auditorium logos
│   └── banners/          # 16:9 panoramic cinema foyer and hall photos
├── avatars/              # 1:1 circular/square customer and staff profiles
├── events/               # 16:9 live events, stand-up comedy, sports screenings
├── offers/               # Promotional coupon banners and badge artwork
├── icons/                # System vector badges and format insignias
└── illustrations/        # Empty state illustrations, error vectors, 404 banners
```
